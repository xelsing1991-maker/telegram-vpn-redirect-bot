# 🚀 Telegram VPN Redirect Bot

Простой Python-бот для Telegram, который запускает один или несколько ботов и отправляет пользователю красивое приветственное сообщение с кнопками-переходами на нужный VPN-сайт, лендинг, оплату или страницу выдачи доступа.

## ✨ Что умеет

- 🤖 Запускает несколько Telegram-ботов из одного скрипта.
- 🔗 Показывает inline-кнопки с переходом на заданный URL.
- 🎯 Рандомизирует главный текст кнопки, чтобы тестировать разные CTA.
- 🛠 Позволяет администратору добавить новый токен командой `/add <token>`.
- 📊 Имеет команду `/stats` для просмотра локальной статистики из `button_stats.json`.
- 🔁 Может перезапустить systemd-сервис после добавления нового бота.

## 🧩 Для чего использовать

Проект подходит как основа для:

- 🌐 VPN-воронки в Telegram;
- 📣 рекламных ботов с кнопкой перехода на лендинг;
- 🧪 A/B-тестов текстов кнопок;
- 🧑‍💻 быстрого запуска сетки однотипных Telegram-ботов;
- 💳 перенаправления пользователей на оплату, поддержку или личный кабинет.

## ⚙️ Установка

```bash
git clone https://github.com/<username>/<repo>.git
cd <repo>
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## 🔐 Настройка токенов

Скопируйте пример:

```bash
copy bot_tokens.example.json bot_tokens.json
```

Добавьте токены ботов от [@BotFather](https://t.me/BotFather):

```json
[
  "123456789:your_real_token",
  "987654321:another_real_token"
]
```

Файл `bot_tokens.json` добавлен в `.gitignore`, поэтому реальные токены не попадут в публичный репозиторий.

## 🔗 Настройка ссылки

В файле `multi_bot_redirect.py` замените:

```python
REDIRECT_URL = "youurl.com"
```

на свой адрес:

```python
REDIRECT_URL = "https://example.com"
```

## 👑 Администраторы

В `ADMIN_IDS` укажите Telegram ID пользователей, которым доступны команды администратора:

```python
ADMIN_IDS = {
    123456789,
}
```

## ▶️ Запуск

```bash
python multi_bot_redirect.py
```

После запуска каждый токен из `bot_tokens.json` стартует в отдельном потоке.

## 🧾 Команды

- `/start` — отправить пользователю приветствие и кнопки.
- `/stats` — показать локальную статистику для текущего бота.
- `/add <token>` — добавить токен нового бота и перезапустить сервис.

## 🛡 Безопасность

Не публикуйте:

- реальные Telegram-токены;
- файлы статистики с пользовательскими ID;
- `.env` и другие локальные секреты.

Для этого в проекте уже настроен `.gitignore`.
